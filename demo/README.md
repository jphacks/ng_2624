# ローカルデモ

リポジトリのルートで `npm run demo` を実行し、表示される `http://localhost:3001/demo` を開きます。通常の `npm start` とは別の入口です。Google/Supabaseの設定は不要です。

保護者・子ども各1人を作り、残高0ポイント、会話・目標・お手伝いなしで開始します。「保護者で入る」「子どもで入る」で通常のアプリ画面へ進めます。親子接続は、保護者の子ども管理から招待を発行し、同じPCの別ブラウザーまたはプライベートウィンドウで招待URLを開いて試せます。子どものログインボタンを押さずに招待URLを開いてください。

データはPGliteのメモリ内にだけ保存します。終了・再起動またはデモ操作画面の「デモを初期化する」で消去されます。リセットは別ブラウザーのデモセッションも無効にします。通常アプリとはCookie名を分けています。

AI会話は通常と同じ実装を使用します。`.env` の `GEMINI_API_KEY` が必要で、AIと商品確認では外部サービスへ通信します。デモの認証・DBではSupabaseへ接続しません。キーがない場合、ログイン・子ども管理・接続などは利用できますがAI会話は設定エラーになります。

ポート変更は `DEMO_PORT=3002 npm run demo`。必要なら `DEMO_ORIGIN=http://127.0.0.1:3002` も指定できます。ホストはループバックに限定しており、他の端末からのアクセスや公開用の設定は利用できません。通常の `PORT`、`APP_ORIGIN`、Supabase設定はデモに適用しません。
