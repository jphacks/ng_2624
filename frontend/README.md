# フロントエンド（画面の試作）

ブラウザだけで動く画面です。インストールやビルドは不要です。

## 開き方

### 仮モード（いちばんかんたん）
`frontend/index.html` をダブルクリックしてブラウザで開くだけで動きます。
AIの返事や提案のやりとりは、ブラウザの中の仮バックエンドが決まった内容を返します。

### 本物のバックエンドにつなぐモード（`?api=supabase`）
`http://` のURLで開く必要があります。ダブルクリック（`file://`）で開くと、仮モードのままになります。

1. VS Code に拡張機能 **Live Server** を入れる
2. `frontend/index.html` を右クリック →「Open with Live Server」
3. 開いたURLの最後に `?api=supabase` を付けて開き直す
   例：`http://127.0.0.1:5500/frontend/index.html?api=supabase`

このモードでは、子どものトークの**AIの返事だけ**を、BEの Supabase Edge Function `ai-reply` に送ります。ほかの操作は仮モードのままです。

> 今は接続先（URL・anon キー）とログインがまだ設定されていません。そのため送信すると
> 「AIにつなぐ準備がまだです。（接続先の設定が必要です）」と出て止まります。これは正常な動きです。

## モードの一覧

| URLの最後 | AIの返事 | ほかの操作 |
| --- | --- | --- |
| なし | 仮の返事 | 仮バックエンド |
| `?api=supabase` | BEの `ai-reply` | 仮バックエンド |
| `?api=real` | BEの `ai-reply` | 本物のバックエンド（`/api/...`。FE-BE接続の仕様書どおり） |

## 試してほしい流れ（仮モード）

1. 「子どもとして始める」→ トークを開く
2. 何か送る → AIの返事が出る
3. もう1回送る → 商品カードが3つ出る
4. 「これにする」→ 提案を確認・編集して送信
5. 最初の画面に戻って「親として始める」→ 子どもの提案が届いている

再読み込みすると、仮モードのデータは消えます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面のHTML |
| `style.css` | 見た目 |
| `app.js` | 画面の動き |
| `api.js` | バックエンドとのやりとり（送る形・受け取る形のチェック、仮バックエンド） |
| `data.js` | 画面に出す仮データと、仮バックエンドの決まった返事 |

## キーの扱い（大事）

- フロントに書いてよいのは、Supabase の **anon キー（publishable key）** だけです。`api.js` の `SUPABASE` に入れます。
- `service_role` キー（`sb_secret_...`）と `GEMINI_API_KEY` は、絶対にフロントに書かないでください。どちらもBEの中だけで使います。
